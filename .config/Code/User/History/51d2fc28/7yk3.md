# Discussion Router Configuration

This document explains the discussion router setup and how to use it.

## Overview

The discussion router is configured to handle GitHub-style pull request and discussion pages. It uses React Router DOM for client-side routing.

## Routes

### Available Discussion Routes

- `/discussion/:id` - Main discussion/pull request page

### Future Routes (commented out for now)

- `/discussions` - List all discussions
- `/discussion/:id/files` - Files changed in the pull request
- `/discussion/:id/commits` - Commits in the pull request

## File Structure

```
src/router/
├── index.tsx              # Main router configuration
├── discussionRoutes.tsx   # Discussion-specific routes
├── discussionUtils.ts     # Navigation utility functions
├── useDiscussionNavigation.ts # Custom navigation hook
└── router.ts             # Export index for router functionality
```

## Usage

### Basic Navigation

```tsx
import { useDiscussionNavigation } from '../router/useDiscussionNavigation';

function MyComponent() {
	const { goToDiscussion, currentDiscussionId } = useDiscussionNavigation();

	const handleViewDiscussion = (id: string) => {
		goToDiscussion(id);
	};

	return (
		<button onClick={() => handleViewDiscussion('123')}>
			View Discussion #123
		</button>
	);
}
```

### Using Navigation Utilities

```tsx
import {
	navigateToDiscussion,
	extractDiscussionId,
} from '../router/discussionUtils';

// Generate URL for a discussion
const discussionUrl = navigateToDiscussion('123'); // '/discussion/123'

// Extract ID from current pathname
const id = extractDiscussionId('/discussion/123'); // '123'
```

### Router Hook Features

The `useDiscussionNavigation` hook provides:

- `goToDiscussion(id)` - Navigate to a specific discussion
- `goToDiscussionFiles(id?)` - Navigate to files tab (future)
- `goToDiscussionCommits(id?)` - Navigate to commits tab (future)
- `goBack()` - Go back in history
- `currentDiscussionId` - Current discussion ID from URL
- `isOnDiscussionRoute` - Boolean if on any discussion route

## Integration

The discussion router is integrated into the main app through:

1. **Main Router** (`src/router/index.tsx`) - Contains all application routes
2. **App Component** (`src/App.tsx`) - Uses `AppRouter` component
3. **Discussion Page** (`src/app/discussion/[id]/page.tsx`) - Uses the navigation hook
